# Security policy

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** private reporting feature. Do not open a public issue containing exploit details, credentials, account identifiers, Terraform state, or plan output.

You should receive an acknowledgement within seven days. This learning repository is maintained on a best-effort basis and does not provide a production support SLA.

## Supported version

Security fixes target the latest commit on `main`. Pin released tags when using the project as a reference and review every Terraform plan before deployment.
